# Support Runbook

AtlasDB read replica lag is investigated with the replica health panel, replication queue depth, and the latest failover event. If lag exceeds five minutes, support should page the database owner.

The KB-209 password reset workflow applies to locked enterprise accounts. Support must verify the customer domain, open the recovery ticket, and invalidate all existing sessions before issuing a temporary login link.

When search indexing appears stale, check queue age, failed parser jobs, and the last successful vector ingestion timestamp. Requeue only the affected document batch rather than rebuilding the full knowledge base.

For billing disputes, support should attach the invoice id, customer plan, and renewal date before escalating to finance.
