# Employee Handbook

The ORION-17 onboarding checklist is used for new engineering hires. It requires account creation, security training, laptop enrollment, and a mentor assignment within the first three business days.

New hires must activate VPN access before their first Monday standup. If badge access is delayed after building hours, employees should call the facilities hotline and ask the on-call manager to approve temporary lobby access.

Remote employees traveling for company work must keep a backup recovery code in the password vault. If a hardware token is lost during travel, the employee should notify security and ask the people team for temporary travel access.

Managers should confirm that probation goals are documented before the end of week two. The handbook does not define payroll tax rates or cafeteria menus.
